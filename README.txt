RAZIEL ACROSS NOSGOTH
Installation and troubleshooting for the Windows preview

WHAT YOU NEED
Install Soul Reaver 1 & 2 Remastered and Defiance Remastered on a 64-bit Windows PC. This preview runs in Soul Reaver 1 and uses Defiance in the background. You can use supported builds from Steam, another store or a standalone installation. The EXE contains the mod runtime and the companion save.

INSTALL
1. Close both games. If you have an older copy of this mod, uninstall it first.
2. Double-click Raziel Across Nosgoth Setup.exe. Approve the Windows administrator prompt to let Setup update the game folders.
3. Click Next and check the two detected game folders. If a folder is missing or incorrect, use Browse or enter the path. Choose the Soul Reaver folder containing SRX.exe and the Defiance folder containing defiance.exe. Click Next to confirm.
4. Review the folders and click Install. If you see an unknown version warning, click Cancel to return to the wizard. Install anyway copies the package and save but leaves the mod inactive. To activate it later, uninstall the mod, install supported game builds and run Setup again.
5. Read the guide and click Finish. Setup adds the Raziel Across Nosgoth desktop shortcut and a Defiance Chapter 10 save. It backs up any existing save in that slot.

PLAY
1. Open Raziel Across Nosgoth from the desktop. Defiance loads Chapter 10 and hides. Wait for Soul Reaver 1 to open, then load your Soul Reaver save or start a game.
2. Once you can move, press F10 once. Raziel may briefly stop moving while the mod starts. The light circle by the Windows clock means the mod is on. Look in the hidden tray icons if you cannot see it. Press F10 again to turn the mod off. F7 opens the control guide.
3. Leave Defiance running in the background. For an ordinary Soul Reaver 1 play session, start the game from its usual shortcut or leave the mod off.

UNINSTALL
1. Close Soul Reaver and Defiance. If Defiance is hidden, use Exit Launcher from the mod icon beside the clock or bring Defiance back with Show Defiance and close it normally.
2. Open Windows Settings, then Apps and Installed apps. Find Raziel Across Nosgoth Preview and choose Uninstall. Approve the Windows prompt if asked.
3. Uninstall removes the desktop shortcut and mod files. It restores the Defiance save backed up by Setup. Your other saves stay in their game folders. If a file was changed after installation, the uninstaller shows the affected path so it can be checked before retrying.

TROUBLESHOOTING
Defiance stays open or Soul Reaver never appears. Close both games, including any hidden instance, and start from the mod shortcut. If you moved or updated a game, uninstall the mod and run Setup again.
F10 appears to do nothing. Return focus to Soul Reaver, close its menus and wait until Raziel can move. Press F10 once and wait for the light tray circle. If it stays off, restart from the shortcut.
Raziel cannot move after activation. Give startup time to finish. If the tray still says Starting, press F10 once to cancel. If movement does not return, exit the launcher and both games, then start again from the shortcut.
The mod stops after a long pause, Alt+Tab or a story scene. Return to the game and check the tray icon. If the mod is off, press F10 to restart it. If you still cannot move, close both games and relaunch.
Setup detects another mod loader. Keep your existing files and remove the other loader using its own uninstall instructions before retrying.

WORK IN PROGRESS
Some encounters, animations and transitions may behave differently from the original game. When reporting an issue, include the game versions, area, action and whether the tray icon changed. You can open the launcher logs by pasting %LOCALAPPDATA%\RazielAcrossNosgoth\runtime into File Explorer's address bar. Share the newest launcher-errors.log or runner log if it shows the problem.
