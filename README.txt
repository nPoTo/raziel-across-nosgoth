RAZIEL ACROSS NOSGOTH — R118

REQUIRES
Windows 10/11 x64, Soul Reaver 1 & 2 Remastered, and Defiance Remastered.
Keep both games installed. Defiance does not need to run.

INSTALL OR UPDATE
1. Close both games.
2. Extract Raziel-R118-Installer.zip and run Raziel R118 Setup.exe.
3. Choose your Soul Reaver and Defiance installation folders. Click Next, Install, Finish.
4. Start SR1 through Steam, SRX.exe or your shortcut, load a save and press F10.
   Allow the first resource loading to finish. F7 opens the guide and Combo controls.

MAIN BUTTONS
F10 — mod On/Off. F7 — guide. F6 — Reaver On/Off.
F9 — save your current powers, HP and mana, then grant everything. Press again to restore.
Attack — X / left click. Lift or air slam — Y / right click.
Lock — hold LB / Shift. Dodge — direction + LB + A / direction + Shift + Space.
Telekinesis — B / F. Feed or finish a stunned enemy — RB / E.
Change sword — D-pad Left/Right / Z and X. Glyph menu — View / Tab.
Quick realm shift — D-pad Down, release, then A. Use a portal to return to Material.
Original Debug — F10 Off, release buttons, then B + X / E + left click.

STORY AND SWORDS
You can fight the first Kain unarmed. F6 gives or removes the Reaver.
Glyphs unlock swords: Force = Dark, Stone = Earth, Water = Water,
Sound = Wind, Fire = Fire, Sunlight = Light. All seven Glyphs unlock Spirit.
Standard swords deal 500 + 300 per unlocked elemental form, up to 2,300.
Spirit deals 5,000. One measured SR1 Sluagh has 6,144 HP; one Ronin variant has 15,360.
Variants, regeneration and special vulnerability rules affect the number of hits.
During the new first Kain fight, damage uses its own rules. Normal sword hits take
1–2% of his total HP, fists 5–7%, and Spirit 10%. Damaging Glyphs take up to 10%
and cannot finish him; Force pushes him away. Raziel gets 500,000 internal HP for
this encounter while keeping the usual spiral size. His pre-door status returns
before the ending scene. Load a save before the door to test the complete sequence.

AUTOMATIC UPDATES
Starting SR1 checks GitHub in the background. No new version means no popup.
Choose Yes to download, watch the progress bar, then Yes to install.
Save first. Install Yes closes the games. Success shows DONE, the version and Finish.
Existing installations can update from the offer shown when SR1 starts online.

UNINSTALL
Close both games. In the SR1 folder open RazielR60 and run Uninstall R60.exe.
It restores the files backed up during installation. Saves are preserved.
